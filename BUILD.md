# Building Sakugo Studio

The JavaScript, HTML and CSS in `src/` are hand-written source and ship as they are. There is no transpiler, bundler or minifier. `node` and `npm` are not used.

## Environment

- Linux (built on Arch Linux, x86-64). Any OS with Python should do for step 1.
- Python 3.14.7. Step 1 uses only the standard library.
- Step 2 also needs Pillow 12.3.0 and numpy 2.5.3: `pip install Pillow==12.3.0 numpy==2.5.3`

## 1. Build the package

```sh
python3 tools/pack.py
```

This zips `manifest.json`, `README.md`, `LICENSES`, `icons`, `fonts`, `scenes`, `src` and `vendor` into `dist/sakugo-studio-<version>.xpi`. Every file in the package is the same as the file in this folder. The files generated by the steps below are already in place, so this step is all that is needed for an exact copy.

## 2. Optional: regenerate the scenes

```sh
python3 tools/art/finish.py art-src .
```

From `art-src/sharp/*.png` and `tools/art/catalog.json` this writes `scenes/*.webp`, `src/shared/scenes.js` and `LICENSES/scene-credits.md`. With the versions above the output is byte-identical to the included files. `src/shared/scenes.js` is the only generated script, and it holds only data: scene names and colour statistics.

## Files not built from this folder

- `vendor/pdfjs/`: unmodified files from the `pdfjs-dist` npm package, version 6.5.438 (https://www.npmjs.com/package/pdfjs-dist). Apache-2.0.
- `fonts/`: subsets of open fonts under the SIL OFL (`LICENSES/`), made with `tools/build_fonts.py`. The full source fonts are not included. They come from Google Fonts and the projects named in `LICENSES/`.
- `art-src/sharp/`: the AI-generated pictures the scenes are made from, after clean-up with `tools/art/unmark.py` and `tools/art/sharpen.py`. Their sources are listed in `LICENSES/scene-credits.md`. The earlier originals are not included.
